# 🗂️ سامانه «دفتر» (Daftar)
> سامانه بومی و متمرکز مدیریت دارایی‌های دیجیتال، دسترسی‌ها، مستندات فنی و یادآورهای تمدید سازمانی در شبکه محلی (On-Premise LAN)

---

## 🎯 معرفی و هدف پروژه

در بسیاری از سازمان‌ها و شرکت‌ها، اطلاعات حیاتی مانند دسترسی به سرورها (VPS)، اکانت‌های سازمانی، ایمیل‌ها، لایسنس نرم‌افزارها، دامنه‌ها و تنظیمات شبکه، به صورت پراکنده در فایل‌های اکسل ناامن، نوت‌پدها یا پیام‌رسان‌ها نگهداری می‌شوند. این موضوع چالش‌های بزرگی از جمله **عدم امنیت رمزهای عبور**، **عدم وجود ردیابی تغییرات (Audit Trail)**، **فراموشی تاریخ سررسید و انقضای سرویس‌ها** و **دسترسی نداشتن به راهنماهای فنی راه‌اندازی** ایجاد می‌کند.

**«دفتر»** طراحی شده است تا با رابط کاربری کاملاً فارسی و منعطف شبیه به اکسل/نوشن، امکان تعریف هر نوع موجودیت یا دارایی دیجیتال با فیلدهای کاملاً سفارشی را فراهم کند؛ در حالی که امنیت سطح فیلد (Field-Level Encryption) با الگوریتم AES-256، جستجوی سریع سراسری، مدیریت مستندات داخلی با فرمت Markdown و سامانه سررسید با تقویم شمسی را به ارمغان می‌آورد.

---

## 🚀 ویژگی‌های کلیدی نسخه اول (v1)

- **طراحی فیلدهای پویا (Dynamic Field Schema Builder):** تعریف انواع دارایی‌ها (مانند VPS، ایمیل، سوئیچ، دامنه‌ها، نرم‌افزارهای ابری) با انواع فیلدهای متنی، رمزهای عبور محافظت‌شده، آدرس IP/پورت، URL، تاریخ شمسی و لیست‌های انتخابی.
- **امنیت پیشرفته داده‌ها (AES-256-GCM Encryption):** رمزنگاری داده‌های حساس در سطح پایگاه‌داده به صورت متقارن و غیرقابل خواندن در فایل‌های بکاپ خام دیتابیس.
- **نمای جدولی پیشرفته اکسل‌گونه (Data Grid View):** جدول واکنش‌گرا با قابلیت مرتب‌سازی، فیلتر آنی، مخفی/آشکارسازی ستون‌ها و کپی داده‌ها (IP، یوزر، پسورد) با **تنها ۱ کلیک**.
- **مستندات دو لایه (Markdown & File Attachments):** 
  - یکپارچه‌سازی مستندات و راهنماهای جامع به زبان Markdown در سطح هر «نوع دارایی» (مثلاً راهنمای کلی کار با سرورها).
  - یادداشت‌های اختصاصی Markdown و پیوست فایل‌های پیکربندی تا سقف ۵۰ مگابایت برای هر «تک دارایی».
- **سامانه ردیابی و ممیزی رویدادها (Audit Trail):** ثبت دقیق اینکه چه کاربری، در چه زمانی، کدام مقدار را ویرایش کرده است (Diff Tracker) و لاگ‌گیری اختصاصی برای رویدادهای «مشاهده یا کپی رمز عبور» بدون افشای مقدار محرمانه در لاگ.
- **سامانه مدیریت تمدیدها و سررسیدها (Renewal Reminders):** محاسبه سررسید بر پایه گاه‌شمار هجری شمسی، هشدارهای چندمرحله‌ای (۳۰، ۷ و ۱ روز مانده به موعد)، نشانگرهای وضعیت در داشبورد و ثبت تاریخچه تمدیدها و فاکتورها.
- **جستجوی سراسری ایمن (Global Search):** جستجوی سریع روی عناوین، آدرس‌های IP، تگ‌ها و فیلدهای متنی با حفاظت کامل از فیلدهای پسورد.
- **ورودی و خروجی اکسل و بکاپ خودکار:** قابلیت ایمپورت فایل‌های اکسل قدیمی، خروجی گزارش‌ها در قالب Excel/CSV و اسکریپت بکاپ‌گیری منظم دیتابیس.
- **استقرار ایمن در شبکه محلی (Local HTTPS):** پشتیبانی توکار از HTTPS با گواهی خودامضا در بسته‌ی داکر، تضمین‌کننده کارکرد درست قابلیت Clipboard Copy در مرورگرهای جدید.

## 🛠️ استک تکنولوژی (Technology Stack)

- **Frontend:** React 18+ (Vite) + TypeScript + Tailwind CSS (RTL) + Lucide Icons + Jalali Moment / Datepicker + TanStack Table
- **Backend:** Node.js 20+ (Fastify یا Express با TypeScript) + Prisma ORM / Kysely
- **Database:** PostgreSQL 16 (بهره‌گیری از ایندکس‌های GIN روی ستون‌های JSONB)
- **Encryption:** Node.js Crypto (AES-256-GCM با IV تصادفی و Auth Tag)
- **Reverse Proxy:** Caddy v2 یا Nginx (مدیریت HTTPS با گواهی خودامضا برای شبکه داخلی)
- **Orchestration:** Docker & Docker Compose
